# Code of conduct

We want this project to be a constructive environment for researchers,
engineers, students, and reviewers.

Be respectful, specific, and evidence-driven. Critique claims, artifacts, and
methods rather than people. Do not harass, threaten, discriminate against, or
publish private information about others.

Maintainers may remove content or participation that violates these
expectations. Report conduct concerns privately through the repository owner's
GitHub profile.
